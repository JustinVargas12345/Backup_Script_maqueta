FLUJO RÁPIDO (TL;DR)
================================================================================

PowerShell:

  # 1. Construir (una sola vez, ~5 min)
  make build-image
  
  # 2. Ejecutar backup (1-5 min)
  .\scripts\run_backup_docker.ps1 -DbType postgres -Database mydb -User postgres
  
  # 3. Ver backup guardado
  ls .\backups

El script automáticamente:
  ✓ Pide contraseña segura (sin mostrar)
  ✓ Verifica/construye imagen
  ✓ Ejecuta dentro del contenedor
  ✓ Guarda en ./backups
  ✓ Limpia variables sensibles

================================================================================
SEGURIDAD: CONTRASEÑAS
================================================================================

✅ SEGURO (lo que hace el script):
   $Password = Read-Host -AsSecureString  # Sin mostrar
   docker run -e PGPASSWORD=$Password ... # Solo al contenedor
   Remove-Item Env:PGPASSWORD             # Limpia después
   
   → Contraseña nunca aparece en pantalla, historial o archivos

❌ INSEGURO (nunca hagas):
   docker run ... --password "MiPassword123" ...
   
   → Contraseña visible en historial, logs, procesos

El script PowerShell implementa automáticamente el patrón seguro.

EJEMPLOS POR BD
================================================================================

PostgreSQL:
  .\scripts\run_backup_docker.ps1 -DbType postgres -Database mydb -User postgres

MySQL:
  .\scripts\run_backup_docker.ps1 -DbType mysql -Database mydb -User root

MongoDB:
  .\scripts\run_backup_docker.ps1 -DbType mongo -Database mydb -User admin

SQL Server:
  .\scripts\run_backup_docker.ps1 -DbType sqlserver -Database mydb -User sa

Con compresión:
  .\scripts\run_backup_docker.ps1 -DbType postgres -Database mydb -User postgres -Compress zip

Con notificación webhook:
  .\scripts\run_backup_docker.ps1 -DbType postgres -Database mydb -User postgres -NotifySlack

================================================================================
TROUBLESHOOTING RÁPIDO
================================================================================

❌ "docker: command not found"
   → Reinstala Docker Desktop o reinicia PowerShell

❌ "permission denied"
   → Solo Linux: sudo usermod -aG docker $USER

❌ "container exited with error"
   → Verifica contraseña, host, usuario en la BD
   → Asegúrate que la BD está corriendo

❌ "image not found"
   → Ejecuta: make build-image

✅ "Backup completado exitosamente"
   → Archivo está en ./backups

Ver más troubleshooting en: DOCKER_PASO_A_PASO.md sección "Troubleshooting"
